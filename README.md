# Insurance Brokerage — Client App

> Interactive mobile app prototype for insurance brokerage clients, featuring policy management, renewal alerts and self-service quoting.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Insurance & brokerage

Interactive mobile app prototype for insurance brokerage clients, featuring policy management, renewal alerts and self-service quoting.

**Highlights**

- Policy wallet with coverage details and beneficiaries
- Renewal reminders and expiry alerts
- In-app quoting and digital purchase

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
